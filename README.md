# Desafíos de Programación Básicos

Este repositorio contiene una colección de ejercicios de programación básicos diseñados para fortalecer tus habilidades en diferentes lenguajes de programación. Estos desafíos cubren una variedad de conceptos fundamentales, como:

* **Control de flujo:** condicionales, bucles
* **Estructuras de datos:** listas, cadenas
* **Algoritmos:** búsqueda, ordenamiento, recursión

## Ejercicios Incluidos

* **Fizz Buzz:** Imprime los números del 1 al 100. Pero para los múltiplos de 3, imprime "Fizz" en lugar del número. Para los múltiplos de 5, imprime "Buzz". Para los números que son múltiplos de ambos 3 y 5, imprime "FizzBuzz".
* **Anagramas:** Determina si dos cadenas de caracteres son anagramas entre sí, es decir, si una se puede formar reordenando las letras de la otra.
* **Sucesión de Fibonacci:** Genera los primeros n términos de la sucesión de Fibonacci.
* **Números primos:** Determina si un número dado es primo.
* **Inversión de cadenas:** Invierte el orden de los caracteres en una cadena.
